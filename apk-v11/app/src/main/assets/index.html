테스트 데이터

이 프로토타입의 기록은 브라우저에 저장됩니다. 초기화하면 처음 상태로 돌아갑니다.

테스트 방법

  1. 레슨에서 1~40장 목록과 화면 이동을 확인하세요.
  2. 1장에서는 Dialogue 1 / Dialogue 2 / Conversation / 역할극 / 쉐도잉 / 발음 / 문제풀이가 실제로 동작합니다.
  3. Dialogue에서는 ±10초 이동, 진행바, 현재 문장 강조, 자동스크롤, 한글 해석 숨김, 1·3·5회 반복, A–B 구간반복을 시험할 수 있습니다.
  4. 대화 음성은 영국식(en-GB)을 우선 사용합니다. 화면에 실제 선택된 여성/남성 음성 이름이 표시되며, 각각 테스트하거나 서로 교체할 수 있습니다.
  5. 쉐도잉 녹음은 브라우저에서 마이크 권한을 허용해야 합니다.
  6. MP3 연결 테스트에서 휴대폰/PC의 음원 파일을 직접 선택할 수 있습니다.
