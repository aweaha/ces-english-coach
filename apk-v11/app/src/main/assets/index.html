40장 진행률

완료 레슨은 기기에 저장됩니다.

CES English Coach

  1. 레슨에서 교재 1~40장을 모두 선택할 수 있습니다.
  2. 각 장의 Dialogue / Conversation은 교재에 실제 존재하는 개수대로 표시됩니다.
  3. 회화 화면에서 ±10초, ▶/⏸/⏹, 1·3·5회 반복, A/B, 한글 ON/OFF를 사용할 수 있습니다.
  4. Role Play / Shadowing은 현재 선택한 대화로 연습합니다.
  5. Pronunciation Clinic / Listening·Exercise도 각 장의 교재 원문을 수록했습니다.
  6. 음성은 영국식(en-GB)을 우선 사용하고 남/여 화자를 구분합니다.
